# Word choices

Common words that ASD-STE100 does not approve, with the usual replacement. This is a working
subset, not the dictionary. When a word is not on this list and you are unsure, apply the
heuristic: choose the shortest, most common, most concrete word; prefer a plain verb plus a noun
over a rare single verb.

## Nouns that are not verbs

Some approved words are nouns only. Make the action with a plain verb plus that noun.

| Avoid | Use |
|---|---|
| Test the pump. | Do a test of the pump. |
| Check the pressure. | Do a check of the pressure. Or: Look at the pressure gauge. |
| Function (as a verb) | operate (`the pump operates`) |
| Monitor the temperature. | Watch the temperature. |
| Access the panel. | Get access to the panel. |
| Impact the schedule. | Have an effect on the schedule. |
| Reference the manual. | Refer to the manual. |
| Interface with the bus. | Connect to the bus. |

## Software and documentation contexts

STE comes from aerospace maintenance, so software prose needs judgment. Keep the identifier,
change the sentence around it.

| Avoid | Use |
|---|---|
| Instantiate the client. | Make a client object. |
| The build is failing. | The build fails. |
| Deprecated (first use) | Do not use this. It will be removed. |
| Once you have installed the CLI ... | After you install the CLI ... |
| This allows you to ... | With this, you can ... |
| Simply run ... | Run ... |
| Make sure to ... | You must ... |
| It's recommended that you ... | Name who recommends it, or give the instruction: Do this. |
| Note that the flag is optional. | The flag is optional. |
| There are three ways to do this. | You can do this in three ways: |
